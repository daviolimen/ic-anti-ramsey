# Iniciação Científica — Problemas Anti-Ramsey

Este repositório reúne o progresso e as atividades desenvolvidas em um projeto de iniciação científica em **Combinatória** e **Teoria dos Grafos**, com foco na preparação para o estudo de problemas do tipo anti-Ramsey.

## Sobre o projeto

Problemas anti-Ramsey investigam condições que garantem a existência de subestruturas cujas arestas possuem cores todas distintas, chamadas de estruturas *rainbow*.

O projeto tem caráter predominantemente formativo. Seu objetivo é desenvolver a base matemática, combinatória e probabilística necessária para compreender resultados da área e, posteriormente, iniciar investigações próprias. Entre os tópicos estudados estão técnicas de demonstração, princípios de contagem, resultados elementares de Teoria dos Grafos, método probabilístico e grafos aleatórios.

## Objetivos

- Desenvolver familiaridade com argumentos e técnicas combinatórias;
- Estudar conceitos fundamentais de Teoria dos Grafos;
- Introduzir o método probabilístico e o modelo de grafos aleatórios `G(n,p)`;
- Compreender as definições básicas da teoria anti-Ramsey;
- Aplicar as ferramentas estudadas em problemas introdutórios de coloração.
